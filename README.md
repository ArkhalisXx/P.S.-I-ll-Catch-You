# P.S. I’ll Catch You 💌

A tiny anniversary platformer starring Axel and Swayze. Cross ten illustrated chapters of a folded paper world, collect hearts, and help each other reach the final card.

## Play

Download or clone this repository, then open `index.html` in a modern browser. The game runs offline with no build step or external dependencies.

Use the arrow keys or **A/D** to move, **Space** to jump, and **X** to fold the card and swap characters. Press **P** or **Escape** to pause. Touch controls are available on phones and tablets. Completed chapters and sound preferences are saved in this browser when storage is available.

## Make it yours

Edit the anniversary message inside the `ending-note` element in `index.html` before giving the game as a gift.

The world is rendered on a 640×272 pixel canvas. Axel and Swayze each use original animated 32×32 pixel sprites.
